> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기록 화면에서 앨범 영상을 고르거나 카메라로 60초까지 찍어 붙이고, 앱이 1080p H.264 로 압축해 포스터와 함께 사진과 같은 3단계로 올리며, 타일·넘기기에 재생 표시와 길이, 크게 보기에서 그 자리 재생과 원본(mp4) 앨범 저장을 한다. 60초를 넘으면 앞 60초만 올리고 알린다.

**Architecture:** 여덟 작업이다. ① 플러그 자리(`MediaPicker` 영상 둘, `VideoTranscoder` 채널·대역, 권한 문자열) ② iOS 네이티브(`AVAssetExportSession`·`AVAssetImageGenerator`) ③ Android 네이티브(`Media3 Transformer`·`MediaMetadataRetriever`) ④ 대기열의 영상 항목과 `issueVideo` ⑤ 기록 화면(추가 시트 넷·타일 배지·3편 한도·안내) ⑥ 크게 보기 재생(`video_player` 를 `core/proxy` 로 감싸고 `AppVideoPlayer`) ⑦ 원본 저장·넘기기·피드 배지 ⑧ 시뮬레이터 흐름과 문서. 서버는 바꾸지 않는다(이미 `kind: video` 를 받는다). 모든 코드는 참조 작업 트리(`.superpowers/ref/wt-video`, 브랜치 `ref/video`, 커밋 185d600 a0c774f 32513d9 3c82d7d 0e09102 43ab0bc 91c090c d15a84d)에서 먼저 돌렸다 — 커밋마다 `flutter analyze` 0·테스트 초록, 작업마다 변이로 판별력 확인, 네이티브 둘은 시뮬레이터·에뮬레이터에서 표본 셋(5초 세로·65초·회전 90° 무음)으로 실제 압축 결과를 확인, 흐름 `video_flow_test.dart` iOS 시뮬레이터 5/5·안드로이드 에뮬레이터 5/5 통과.

**Tech Stack:** Flutter 3.44 · Riverpod 3 · dio · `image_picker`(이미 있음, `pickVideo`) · `gal`(이미 있음, `putVideo`) · **새 의존성: `video_player`(flutter.dev)·`video_player_platform_interface`(dev)**, Android Gradle `androidx.media3:media3-transformer/effect/common`. 자체 네이티브 Swift·Kotlin.

## 이 계획에서 새로 정한 것

설계와 다른 것과 새로 정한 것은 결정 기록 007 의 "④-3a 영상에서 정한 것" 절(작업 8)에 적는다. 요약:
- 압축은 외부 패키지 없이 네이티브(iOS `AVAssetExportSession`·`AVAssetImageGenerator`, 안드로이드 Media3 `Transformer`·`MediaMetadataRetriever`) — `video_compress` 는 19개월 무갱신, `ffmpeg_kit_flutter` 는 discontinued. 채널 하나 `chagocnote/video_transcoder` + 진행률 이벤트 채널.
- 출력 크기는 "짧은 변 1080·긴 변 1920 안, 키우지 않음"(설계 3.3 의 "긴 변 1080" 은 세로 영상을 608×1080 으로 만들어 iOS 프리셋과 어긋난다). 진행률은 시작(0)·끝(1)에 한 번씩 더 보낸다(짧은 영상은 폴링이 한 번도 안 돈다). Media3 `cancel()` 은 리스너를 안 부르므로 핸들러가 직접 `CANCELLED`.
- 60초가 넘으면 앞 60초만(자르는 화면 없음). 컨테이너 길이가 60.27초여도 앱은 내림한 정수를 보내고 서버는 그 정수만 검사한다.
- 대기열 항목에 `trimmed` 칸이 없다 — `addVideo → VideoAddOutcome` 으로 화면이 한 번 안내. 압축은 한 번에 하나(`_transcodeLane`), 빼기는 지금 압축 중인 항목일 때만 네이티브를 멈춘다.
- 한도·크기 문구는 사진·영상 공용(서버 코드가 하나). 권한 문구는 기존 것까지 해요체. 추가 시트는 [사진 찍기]·[앨범에서 사진]·[영상 찍기]·[앨범에서 영상], 한쪽이 차면 회색·누르면 시트 닫고 한도 문구, `addPhotos(attached:)` 는 목록.
- 재생 추상(`VideoPlayback`·`PlaybackState`)은 `design/widgets/video_playback.dart` — 방향은 core → design 하나. 구조 테스트 `plugin_imports_test` 가 "플러그인 직접 import 금지"와 "design 은 core 를 모른다"를 함께 본다. 재생 [다시 시도]는 새 URL 을 돌려받는 `Future<String?> Function()`. 재생 캐시 없음, `moov` 앞(iOS `shouldOptimizeForNetworkUse`).
- 넘기기의 재생 표시는 오른쪽 위 배지 하나. 영상 [원본 저장]을 켬(`mediaFilesProvider` 로 임시 파일 → `Gal.putVideo`). 피드 카드 배지는 서버가 대표의 `kind` 를 주지 않아 없다.
- 남는 것(알고 미룬다): 카메라 촬영·실기기 압축 시간·`cancel/BUSY/TOO_SHORT` 실기·멀티파트·셀룰러·데이터 절약, 안드로이드 재생 오류 "Source error" 구분 불가, 포스터 1px 차이, 크게 보기 삭제 단추 "사진 삭제" 문구.

abstract class VideoTranscoder {
  /// [source]를 앞 [maxSeconds]까지 압축해 [outDir]에 `video.mp4`·`thumb.jpg` 를 쓴다.
  Future<VideoTranscodeResult> transcode(
    String source,
    Directory outDir, {
    int maxSeconds = 60,
    void Function(double progress)? onProgress,
  });

  /// 진행 중인 압축을 멈춘다.

class ChannelVideoTranscoder implements VideoTranscoder {
  ChannelVideoTranscoder({MethodChannel? channel, EventChannel? progress})
    : _channel = channel ?? const MethodChannel(channelName),
      _progress = progress ?? const EventChannel(progressChannelName);

  static const channelName = 'chagocnote/video_transcoder';
  static const progressChannelName = 'chagocnote/video_transcoder/progress';

  static const _codes = {'UNSUPPORTED', 'TOO_SHORT', 'CANCELLED'};

  final MethodChannel _channel;
  final EventChannel _progress;

  @override
  Future<VideoTranscodeResult> transcode(
    String source,
    Directory outDir, {
    int maxSeconds = 60,
    void Function(double progress)? onProgress,
  }) async {
    final subscription = onProgress == null
        ? null
        : _progress.receiveBroadcastStream().listen(
            (value) => onProgress((value as num).toDouble()),
          );
    try {
      final result = await _channel.invokeMapMethod<String, Object?>(
        'transcode',
        {'source': source, 'outDir': outDir.path, 'maxSeconds': maxSeconds},
      );
      return VideoTranscodeResult(
        video: result!['video']! as String,
        thumb: result['thumb']! as String,
        width: result['width']! as int,
        height: result['height']! as int,
        durationSeconds: result['durationSeconds']! as int,
        trimmed: result['trimmed']! as bool,
      );
    } on PlatformException catch (e) {
      throw VideoTranscodeException(
        _codes.contains(e.code) ? e.code : 'UNSUPPORTED',
      );
    } on MissingPluginException {
      // 이 플랫폼에는 압축이 없다(테스트·웹).
      throw const VideoTranscodeException('UNSUPPORTED');
    } finally {
      await subscription?.cancel();
    }
  }

  @override
  Future<void> cancel() async {
    try {
      await _channel.invokeMethod<void>('cancel');
    } on MissingPluginException {
      // 이 플랫폼에는 압축이 없다 — 멈출 것도 없다.
    }
  }

import AVFoundation
import Flutter
import UIKit

/// 영상 압축·포스터(④-3a 설계 3.2절) — Dart `core/proxy/video_transcoder.dart` 의 채널 규약을 따른다.
///
/// `transcode{source, outDir, maxSeconds}` 는 원본의 앞 maxSeconds 를 1080p mp4 로 내보내고
/// 1초 지점 프레임을 JPEG 포스터로 만든 뒤 `{video, thumb, width, height, durationSeconds, trimmed}`
/// 를 돌려준다. 진행률은 이벤트 채널로 0…1 을 보낸다. 외부 패키지 없이 AVFoundation 만 쓴다.
final class VideoTranscoderPlugin: NSObject, FlutterPlugin, FlutterStreamHandler {
  static let channelName = "chagocnote/video_transcoder"
  static let progressChannelName = "chagocnote/video_transcoder/progress"

  /// 포스터 긴 변 — 목록 썸네일 크기(사진 썸네일과 같은 300px).
  private static let posterSide: CGFloat = 300

  /// 진행 중인 내보내기 — 한 번에 하나만, `cancel` 이 멈출 대상.
  private var current: AVAssetExportSession?
  private var progressTimer: Timer?
  private var eventSink: FlutterEventSink?
  private let queue = DispatchQueue(label: "chagocnote.video_transcoder", qos: .userInitiated)

  static func register(with registrar: FlutterPluginRegistrar) {
    let plugin = VideoTranscoderPlugin()
    let channel = FlutterMethodChannel(name: channelName, binaryMessenger: registrar.messenger())
    registrar.addMethodCallDelegate(plugin, channel: channel)
    let progress = FlutterEventChannel(name: progressChannelName, binaryMessenger: registrar.messenger())
    progress.setStreamHandler(plugin)
  }

  func handle(_ call: FlutterMethodCall, result: @escaping FlutterResult) {
    switch call.method {
    case "transcode":
      guard let args = call.arguments as? [String: Any],
            let source = args["source"] as? String,
            let outDir = args["outDir"] as? String,
            let maxSeconds = args["maxSeconds"] as? Int else {
        result(FlutterError(code: "UNSUPPORTED", message: "인자가 올바르지 않다", details: nil))
        return
      }
      // 대기열이 하나씩 보내므로 실제로는 오지 않지만, 겹치면 앞의 세션을 잃는다.
      guard current == nil else {
        result(FlutterError(code: "BUSY", message: "이미 압축 중이다", details: nil))
        return
      }
      transcode(source: URL(fileURLWithPath: source),
                outDir: URL(fileURLWithPath: outDir, isDirectory: true),
                maxSeconds: maxSeconds, result: result)
    case "cancel":
      // 멈춘 세션은 완료 콜백에서 .cancelled 로 끝나 CANCELLED 를 돌려준다.
      current?.cancelExport()
      result(nil)
    default:
      result(FlutterMethodNotImplemented)
    }
  }

  // MARK: - FlutterStreamHandler

  func onListen(withArguments arguments: Any?, eventSink events: @escaping FlutterEventSink) -> FlutterError? {
    eventSink = events
    return nil
  }

  func onCancel(withArguments arguments: Any?) -> FlutterError? {
    eventSink = nil
    return nil
  }

  // MARK: - 압축

  private func transcode(source: URL, outDir: URL, maxSeconds: Int, result: @escaping FlutterResult) {
    let asset = AVURLAsset(url: source)
    // 영상 트랙이 없으면(음성만·손상) 내보낼 것이 없다.
    guard asset.isReadable, !asset.tracks(withMediaType: .video).isEmpty else {
      result(FlutterError(code: "UNSUPPORTED", message: "읽을 수 있는 영상 트랙이 없다", details: nil))
      return
    }
    // 1080p 프리셋이 이 원본과 맞지 않으면 AVFoundation 이 내보내지 못한다.
    guard AVAssetExportSession.exportPresets(compatibleWith: asset).contains(AVAssetExportPreset1920x1080),
          let session = AVAssetExportSession(asset: asset, presetName: AVAssetExportPreset1920x1080) else {
      result(FlutterError(code: "UNSUPPORTED", message: "1080p 로 내보낼 수 없는 영상이다", details: nil))
      return
    }

    let video = outDir.appendingPathComponent("video.mp4")
    let thumb = outDir.appendingPathComponent("thumb.jpg")
    // 내보내기는 이미 있는 파일에 쓰지 못한다 — 다시 시도한 흔적을 지운다.
    try? FileManager.default.createDirectory(at: outDir, withIntermediateDirectories: true)
    try? FileManager.default.removeItem(at: video)

    let limit = CMTime(seconds: Double(maxSeconds), preferredTimescale: 600)
    let trimmed = CMTimeCompare(asset.duration, limit) > 0
    session.outputURL = video
    session.outputFileType = .mp4
    // moov 를 앞으로 — 받는 쪽이 끝까지 받기 전에 재생을 시작할 수 있다.
    session.shouldOptimizeForNetworkUse = true
    // 앞 maxSeconds 만 — 긴 원본은 자르고 trimmed 로 알린다.
    session.timeRange = CMTimeRange(start: .zero, duration: CMTimeMinimum(asset.duration, limit))

    current = session
    startProgress(session)

    session.exportAsynchronously { [weak self] in
      guard let self else { return }
      // 상태 확인·결과 읽기·포스터 만들기는 무거우므로 백그라운드 큐에서.
      self.queue.async {
        let outcome = self.finish(session: session, video: video, thumb: thumb, trimmed: trimmed)
        DispatchQueue.main.async {
          // 짧은 영상은 타이머가 한 번도 돌기 전에 끝난다 — 마지막 값(완료면 1)을 한 번 더 보낸다.
          self.eventSink?(Double(session.progress))
          self.stopProgress()
          self.current = nil
          result(outcome)
        }
      }
    }
  }

  /// 내보내기가 끝난 뒤 결과 영상을 다시 읽어 크기·길이·포스터를 만든다. 실패면 FlutterError.
  private func finish(session: AVAssetExportSession, video: URL, thumb: URL, trimmed: Bool) -> Any {
    switch session.status {
    case .cancelled:
      try? FileManager.default.removeItem(at: video)
      return FlutterError(code: "CANCELLED", message: nil, details: nil)
    case .completed:
      break
    default:
      try? FileManager.default.removeItem(at: video)
      return FlutterError(code: "UNSUPPORTED", message: session.error?.localizedDescription, details: nil)
    }

    // 원본이 아니라 압축본 기준이어야 서버에 올리는 값과 실제 파일이 맞는다.
    let output = AVURLAsset(url: video)
    let duration = CMTimeGetSeconds(output.duration)
    let durationSeconds = duration.isFinite ? Int(duration.rounded(.down)) : 0
    guard durationSeconds >= 1, let track = output.tracks(withMediaType: .video).first else {
      try? FileManager.default.removeItem(at: video)
      return FlutterError(code: "TOO_SHORT", message: nil, details: nil)
    }
    // 세로로 찍은 영상은 naturalSize 가 가로이고 회전이 preferredTransform 에 있다 — 화면에 보이는 크기로.
    let size = track.naturalSize.applying(track.preferredTransform)
    let width = Int(abs(size.width).rounded())
    let height = Int(abs(size.height).rounded())

    // 첫 프레임은 검은 화면이 흔하다 — 1초 지점(짧으면 가운데)을 포스터로.
    let generator = AVAssetImageGenerator(asset: output)
    generator.appliesPreferredTrackTransform = true
    generator.maximumSize = CGSize(width: Self.posterSide, height: Self.posterSide)
    let at = CMTimeMinimum(CMTime(seconds: 1, preferredTimescale: 600),
                           CMTimeMultiplyByRatio(output.duration, multiplier: 1, divisor: 2))
    do {
      let image = try generator.copyCGImage(at: at, actualTime: nil)
      guard let data = UIImage(cgImage: image).jpegData(compressionQuality: 0.8) else {
        return FlutterError(code: "UNSUPPORTED", message: "포스터를 JPEG 로 만들지 못했다", details: nil)
      }
      try data.write(to: thumb, options: .atomic)
    } catch {
      return FlutterError(code: "UNSUPPORTED", message: error.localizedDescription, details: nil)
    }

    return [
      "video": video.path,
      "thumb": thumb.path,
      "width": width,
      "height": height,
      "durationSeconds": durationSeconds,
      "trimmed": trimmed,
    ] as [String: Any]
  }

  // MARK: - 진행률

  /// 내보내기 세션은 진행률을 알려 주지 않는다 — 0.2초마다 읽어 이벤트로 보낸다.
  private func startProgress(_ session: AVAssetExportSession) {
    progressTimer?.invalidate()
    // 시작점 0 을 먼저 — 화면이 바로 진행 막대를 그린다.
    eventSink?(Double(session.progress))
    progressTimer = Timer.scheduledTimer(withTimeInterval: 0.2, repeats: true) { [weak self] _ in
      self?.eventSink?(Double(session.progress))
    }
  }

  private func stopProgress() {
    progressTimer?.invalidate()
    progressTimer = nil
  }
}

 * 내보내고 1초 지점 프레임을 JPEG 포스터로 만든 뒤 `{video, thumb, width, height,
 * durationSeconds, trimmed}` 를 돌려준다. 진행률은 이벤트 채널로 0…1 을 보낸다.
 * 오류 코드·순서는 iOS `VideoTranscoder.swift` 와 같다.
 *
 * Media3 `Transformer` 는 만든 스레드의 Looper 로 콜백하고 그 스레드에서만 부를 수 있다 —
 * 채널 핸들러가 메인 스레드에서 돌므로 만들기·`start`·`cancel`·폴링 모두 메인에서 한다.
 */
@OptIn(UnstableApi::class)
class VideoTranscoderChannel(
    private val context: Context,
    messenger: BinaryMessenger,
) : MethodChannel.MethodCallHandler, EventChannel.StreamHandler {

    private val main = Handler(Looper.getMainLooper())

    /** 진행 중인 압축 — 한 번에 하나만, `cancel` 이 멈출 대상. */
    private var current: Transformer? = null
    private var pendingResult: MethodChannel.Result? = null
    private var pendingVideo: File? = null
    private var lastProgress = 0.0
    private var eventSink: EventChannel.EventSink? = null
    private var poll: Runnable? = null

    init {
        MethodChannel(messenger, CHANNEL).setMethodCallHandler(this)
        EventChannel(messenger, PROGRESS_CHANNEL).setStreamHandler(this)
    }

    override fun onMethodCall(call: io.flutter.plugin.common.MethodCall, result: MethodChannel.Result) {
        when (call.method) {
            "transcode" -> {
                val source = call.argument<String>("source")
                val outDir = call.argument<String>("outDir")
                val maxSeconds = call.argument<Int>("maxSeconds")
                if (source == null || outDir == null || maxSeconds == null) {
                    result.error("UNSUPPORTED", "인자가 올바르지 않다", null)
                    return
                }
                // 대기열이 하나씩 보내므로 실제로는 오지 않지만, 겹치면 앞의 압축을 잃는다.
                if (current != null) {
                    result.error("BUSY", "이미 압축 중이다", null)
                    return
                }
                transcode(File(source), File(outDir), maxSeconds, result)
            }
            "cancel" -> {
                cancel()
                result.success(null)
            }
            else -> result.notImplemented()
        }
    }

    // region EventChannel.StreamHandler

    override fun onListen(arguments: Any?, events: EventChannel.EventSink?) {
        eventSink = events
    }

    override fun onCancel(arguments: Any?) {
        eventSink = null
    }

    // endregion

    private fun transcode(source: File, outDir: File, maxSeconds: Int, result: MethodChannel.Result) {
        // 영상 트랙이 없으면(음성만·손상) 내보낼 것이 없다.
        val info = readInfo(source)
        if (info == null) {
            result.error("UNSUPPORTED", "읽을 수 있는 영상 트랙이 없다", null)
            return
        }

        val video = File(outDir, "video.mp4")
        // 다시 시도한 흔적을 지운다.
        outDir.mkdirs()
        video.delete()

        val limitMs = maxSeconds * 1000L
        val trimmed = info.durationMs > limitMs
        // 앞 maxSeconds 만 — 긴 원본은 자르고 trimmed 로 알린다.
        val mediaItem = MediaItem.Builder()
            .setUri(Uri.fromFile(source))
            .setClippingConfiguration(
                MediaItem.ClippingConfiguration.Builder()
                    .setEndPositionMs(min(info.durationMs, limitMs))
                    .build()
            )
            .build()
        val edited = EditedMediaItem.Builder(mediaItem)
            .setEffects(Effects(emptyList(), listOf(Presentation.createForHeight(targetHeight(info)))))
            .build()

        val transformer = Transformer.Builder(context)
            .setVideoMimeType(MimeTypes.VIDEO_H264)
            .setAudioMimeType(MimeTypes.AUDIO_AAC)
            .addListener(object : Transformer.Listener {
                override fun onCompleted(composition: Composition, exportResult: ExportResult) {
                    lastProgress = 1.0
                    // 결과 읽기·포스터 만들기는 무거우므로 메인 밖에서.
                    thread(name = "chagocnote.video_transcoder") {
                        val outcome = finish(video, File(outDir, "thumb.jpg"), trimmed)
                        main.post { complete(outcome) }
                    }
                }

                override fun onError(
                    composition: Composition,
                    exportResult: ExportResult,
                    exportException: ExportException,
                ) {
                    video.delete()
                    complete(Outcome.Failure("UNSUPPORTED", exportException.toString()))
                }
            })
            .build()

        current = transformer
        pendingResult = result
        pendingVideo = video
        lastProgress = 0.0
        transformer.start(edited, video.path)
        startProgress(transformer)
    }

    /**
     * `Transformer.cancel()` 은 리스너를 부르지 않는다 — 여기서 CANCELLED 로 끝낸다.
     */
    private fun cancel() {
        val transformer = current ?: return
        transformer.cancel()
        pendingVideo?.delete()
        complete(Outcome.Failure("CANCELLED", null))
    }

    /** 압축 하나를 끝낸다 — 마지막 진행률을 보내고 상태를 비운 뒤 Dart 에 답한다. 메인에서만. */
    private fun complete(outcome: Outcome) {
        val result = pendingResult ?: return
        // 짧은 영상은 폴링이 한 번도 돌기 전에 끝난다 — 마지막 값(완료면 1)을 한 번 더 보낸다.
        eventSink?.success(lastProgress)
        stopProgress()
        current = null
        pendingResult = null
        pendingVideo = null
        when (outcome) {
            is Outcome.Success -> result.success(outcome.value)
            is Outcome.Failure -> result.error(outcome.code, outcome.message, null)
        }
    }

    /** 압축본을 다시 읽어 크기·길이·포스터를 만든다. 원본이 아니라 압축본 기준이어야 서버에 올리는 값과 실제 파일이 맞는다. */
    private fun finish(video: File, thumb: File, trimmed: Boolean): Outcome {
        val info = readInfo(video)
        val durationSeconds = ((info?.durationMs ?: 0L) / 1000L).toInt()
        if (info == null || durationSeconds < 1) {
            video.delete()
            return Outcome.Failure("TOO_SHORT", null)
        }

        // 첫 프레임은 검은 화면이 흔하다 — 1초 지점(짧으면 가운데)을 포스터로.
        val atUs = min(1_000_000L, info.durationMs * 1000L / 2)
        val retriever = MediaMetadataRetriever()
        try {
            retriever.setDataSource(video.path)
            // 프레임은 회전 메타가 반영된 채로 나온다.
            val frame = retriever.getFrameAtTime(atUs, MediaMetadataRetriever.OPTION_CLOSEST_SYNC)
                ?: return Outcome.Failure("UNSUPPORTED", "포스터 프레임을 읽지 못했다")
            val scale = POSTER_SIDE / max(frame.width, frame.height).toDouble()
            val poster = if (scale < 1) {
                Bitmap.createScaledBitmap(
                    frame,
                    (frame.width * scale).roundToInt(),
                    (frame.height * scale).roundToInt(),
                    true,
                )
            } else {
                frame
            }
            FileOutputStream(thumb).use { poster.compress(Bitmap.CompressFormat.JPEG, 80, it) }
        } catch (e: Exception) {
            return Outcome.Failure("UNSUPPORTED", e.toString())
        } finally {
            retriever.release()
        }

        return Outcome.Success(
            mapOf(
                "video" to video.path,
                "thumb" to thumb.path,
                "width" to info.width,
                "height" to info.height,
                "durationSeconds" to durationSeconds,
                "trimmed" to trimmed,
            )
        )
    }

    // region 진행률

    /** Transformer 는 진행률을 알려 주지 않는다 — 200ms 마다 읽어 이벤트로 보낸다. */
    private fun startProgress(transformer: Transformer) {
        stopProgress()
        // 시작점 0 을 먼저 — 화면이 바로 진행 막대를 그린다.
        eventSink?.success(lastProgress)
        val holder = ProgressHolder()
        val runnable = object : Runnable {
            override fun run() {
                if (transformer.getProgress(holder) == Transformer.PROGRESS_STATE_AVAILABLE) {
                    lastProgress = holder.progress / 100.0
                    eventSink?.success(lastProgress)
                }
                main.postDelayed(this, PROGRESS_INTERVAL_MS)
            }
        }
        poll = runnable
        main.postDelayed(runnable, PROGRESS_INTERVAL_MS)
    }

    private fun stopProgress() {
        poll?.let { main.removeCallbacks(it) }
        poll = null
    }

    // endregion

    private class Info(val durationMs: Long, val width: Int, val height: Int)

    private sealed class Outcome {
        class Success(val value: Map<String, Any>) : Outcome()
        class Failure(val code: String, val message: String?) : Outcome()
    }

    /** 길이·회전을 반영한 가로·세로. 열 수 없거나 영상 트랙이 없으면 null. */
    private fun readInfo(file: File): Info? {
        val retriever = MediaMetadataRetriever()
        return try {
            retriever.setDataSource(file.path)
            if (retriever.extractMetadata(MediaMetadataRetriever.METADATA_KEY_HAS_VIDEO) != "yes") return null
            val durationMs = retriever.extractMetadata(MediaMetadataRetriever.METADATA_KEY_DURATION)?.toLongOrNull() ?: 0L
            val w = retriever.extractMetadata(MediaMetadataRetriever.METADATA_KEY_VIDEO_WIDTH)?.toIntOrNull() ?: 0
            val h = retriever.extractMetadata(MediaMetadataRetriever.METADATA_KEY_VIDEO_HEIGHT)?.toIntOrNull() ?: 0
            val rotation = retriever.extractMetadata(MediaMetadataRetriever.METADATA_KEY_VIDEO_ROTATION)?.toIntOrNull() ?: 0
            // 세로로 찍은 영상은 가로로 저장되고 회전이 메타에 있다 — 화면에 보이는 크기로.
            if (rotation % 180 != 0) Info(durationMs, h, w) else Info(durationMs, w, h)
        } catch (e: Exception) {
            null
        } finally {
            retriever.release()
        }
    }

    /**
     * 출력 높이 — iOS 1920×1080 프리셋과 같게 짧은 변 1080·긴 변 1920 안에 들어가도록 줄인다(키우지 않는다).
     * Presentation 은 회전이 반영된 프레임에 걸리므로 화면에 보이는 크기로 계산한다. 인코더가 짝수를 요구한다.
     */
    private fun targetHeight(info: Info): Int {
        val short = min(info.width, info.height)
        val long = max(info.width, info.height)
        val scale = min(1.0, min(1080.0 / short, 1920.0 / long))
        if (scale >= 1.0) return info.height
        return ((info.height * scale / 2).roundToInt()) * 2
    }

    private companion object {
        const val CHANNEL = "chagocnote/video_transcoder"
        const val PROGRESS_CHANNEL = "chagocnote/video_transcoder/progress"
        const val PROGRESS_INTERVAL_MS = 200L

        /** 포스터 긴 변 — 목록 썸네일 크기(사진 썸네일과 같은 300px). */
        const val POSTER_SIDE = 300
    }
}

/// [VideoPlayback] 의 video_player 구현 — 화면·모양 위젯이 `video_player` 를 직접 import 하지 않게
/// 감싼 자리(④-3a 설계 5.1).
class VideoPlayerPlayback extends ChangeNotifier implements VideoPlayback {
  VideoPlayerController? _controller;
  Object? _error;

  /// 여는 도중 페이지가 사라질 수 있다(넘겨 버림) — 그 뒤에는 알리지 않는다.
  bool _disposed = false;

  @override
  PlaybackState get state {
    final controller = _controller;
    if (_error != null || controller == null) {
      return PlaybackState(error: _error);
    }
    final v = controller.value;
    return PlaybackState(
      initialized: v.isInitialized,
      playing: v.isPlaying,
      buffering: v.isBuffering,
      position: v.position,
      duration: v.duration,
    );
  }

  @override
  Widget buildSurface() {
    final controller = _controller;
    if (controller == null || !controller.value.isInitialized) {
      return const SizedBox.shrink();
    }
    return AspectRatio(
      aspectRatio: controller.value.aspectRatio,
      child: VideoPlayer(controller),
    );
  }

  @override
  Future<void> open(String url) async {
    final old = _controller;
    _error = null;
    if (old != null) {
      old.removeListener(notifyListeners);
      await old.dispose();
    }
    final controller = _controller = VideoPlayerController.networkUrl(
      Uri.parse(url),
    )..addListener(notifyListeners);
    notifyListeners();
    try {
      await controller.initialize();
      if (_disposed) return;
      await controller.setVolume(1); // 소리는 켠다. 반복은 없다(기본값).
    } on PlatformException catch (e) {
      if (_disposed) return;
      _error = playbackErrorOf(e);
      notifyListeners();
    }
  }

  @override
  Future<void> play() async => _controller?.play();

  @override
  Future<void> pause() async => _controller?.pause();

  @override
  Future<void> seekTo(Duration position) async =>
      _controller?.seekTo(position);

  @override
  Future<void> dispose() async {
    _disposed = true;
    final controller = _controller;
    _controller = null;
    controller?.removeListener(notifyListeners);
    super.dispose();
    await controller?.dispose();
  }
}

/// 플랫폼 오류를 화면이 고를 원인으로. 플랫폼은 HTTP 상태·연결 실패를 오류 메시지 글로만 알린다
/// (iOS 는 CoreMedia -12660 이 403, NSURLError -1009 가 오프라인) — 글에서 찾고, 모르면 원본 그대로.
Object playbackErrorOf(PlatformException error) {
  final text = '${error.message} ${error.details}';
  if (text.contains('403') || text.contains('-12660')) {
    return ApiException(
      statusCode: 403,
      code: 'MEDIA_URL_EXPIRED',
      message: error.message ?? '',
    );
  }
  const offline = [
    'SocketException',
    'UnknownHost',
    'NETWORK_CONNECTION_FAILED',
    '-1009',
    'ENETDOWN',
    'offline',
  ];
  if (offline.any(text.contains)) {
    return ApiException.network(error.message ?? '');
  }
  return error;
}

class DioMediaFiles implements MediaFiles {

  static const receiveTimeout = Duration(seconds: 30);

  @override

    final path =
