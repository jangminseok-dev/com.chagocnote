# ⑪-C3 앱 — 문진표 보내기·받은 문진표·등록 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 사장이 문진표 링크를 한 번 눌러 보내고, 받은 답을 보고 **다시 치지 않고** 고객·반려동물로 등록한다. 문진표에서 물어볼 것은 매장이 서류 설정에서 정한다.

**Architecture:** 전부 `features/customer` 다. 받은 문진표는 고객 정보에 저절로 들어가지 않는다 — 등록 화면(기존 반려동물 폼)을 답으로 **미리 채워** 열고, 저장할 때 `intake_answer_id` 를 함께 보내 서버가 같은 처리 안에서 답을 지운다. 미리 채움 형(`PetPrefill`·`CustomerPrefill`)은 ⑯(글 붙여넣기)이 그대로 쓴다. 전부 네이티브다.

**Tech Stack:** Flutter · Riverpod 3 · go_router.

**Spec:** `docs/superpowers/specs/2026-11-16-consent-intake-design.md`(3.4·3.6 의 4~6·4절), 공통(1·2·3절). 백엔드 계약은 `_docs/decisions/014-consent-intake.md` 의 "⑪-C1 … API 계약".

## Global Constraints

- 편의 기준: **받은 문진표 등록은 답이 다 찼으면 누르기 2번**(줄 → [이대로 등록]), **다시 치는 칸 0**. 빈 필수 칸이 있으면 그 칸만 채운다(지어내지 않는다).
- 문진표를 고객 정보에 반영하는 일은 끝까지 사람이 누른다(공통 2절). 번호가 같은 고객이 미리 이어져 있으면 그 고객의 새 아이로 등록한다.
- 보내는 곳 셋: 고객 탭의 `문진표 링크 보내기`(새 손님) · 고객(가족) 쪽의 `새 아이 문진표 보내기` · 반려동물 상세 [보호자] 탭 맨 아래의 `문진표 다시 받기`. 누르기 한 번으로 공유 시트다(주소만 넘긴다).
- 받은 문진표가 있을 때만 고객 탭 목록 위에 `받은 문진표 N` 이 보인다(0건·읽기 실패면 없다 — 보낸 서류와 같은 규칙).
- 메모 초안이 500자를 넘으면 자르지 않는다 — 넘친 글자 수를 보이고 사장이 줄인다.
- 다시 받기(update)의 반영은 지금 값 위에 **적어 낸 칸만** 덮어 미리 채운다. 기존 메모는 덮지 않고 답을 아래에 덧붙인다.
- 서류 설정: `문진표에서 물어볼 것`(끌 수 있는 칸 여덟의 스위치, 끌 수 없는 칸은 까닭과 함께 보인다), `매장이 더한 질문`(5개까지, 꼭 답하기 여부), `확인하지 않은 문진표를 지우는 때`(7·30·90일 + 직접). 사장만 바꾸고 직원에게는 읽기 전용.
- **앱의 `SentForm` 은 새 손님용 문진표(`customer: null`)와 `kind`·`mode` 를 견딘다** — 모양이 깨진 줄은 버리고 나머지는 보인다.
- **링크 주소(토큰)·이름·전화번호·문진표의 글을 로그·오류 문구·테스트 출력·스크린샷 설명에 남기지 않는다.** `print` 금지, 웹뷰 금지. 해요체. "AI"·"법적 효력" 없음. import 방향 `visit → customer` 만.

## Review Focus

1. **[이대로 등록]을 누르는 사이 다른 기기가 그 답을 등록·지웠다(404)** → 등록되지 않았다고 알리고 목록으로 돌아간다. 고객이 둘 생기지 않는다.
2. **새 손님의 답인데 그 번호의 고객이 그 사이 등록됐다(409)** → 번호가 이미 있다고 알리고, 그 고객의 새 아이로 더하는 길을 준다. 조용히 덮어쓰지 않는다.
3. **답의 품종·몸무게가 비었다(매장이 끈 칸·모르겠어요)** → [이대로 등록]이 그 칸만 묻는 폼으로 간다. 0 이나 "모름"을 지어내지 않는다.
4. **다시 받은 답이 지금 값과 다르다 / 기존 메모가 있다** → 폼이 미리 채워져 있고 무엇이 답에서 왔는지 보인다. 메모는 덮지 않는다.
5. **매장이 질문을 다섯 개 채운 뒤 더하려 한다 / 질문 글이 비었다 / 100자를 넘는다** → 그 자리에서 말하고 보내지 않는다.
